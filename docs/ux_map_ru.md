# UX-карта экранов MVP (v0.1)

## 1) Список экранов
1. **Splash / Welcome**
2. **Onboarding: базовый профиль**
3. **Onboarding: расширенный опрос**
4. **Стартовая оценка подготовки (тесты)**
5. **План на день**
6. **Лог дня (факт выполнения)**
7. **Прогресс**
8. **Профиль и цели**
9. **Источники доказательности**

> Для MVP критичны экраны 2–7; остальные можно запускать как v0.2.

## 2) Основной пользовательский поток
```text
Splash
  -> Onboarding: базовый профиль
  -> Onboarding: расширенный опрос
  -> Стартовая оценка подготовки
  -> План на день
      -> Лог дня
      -> Прогресс
      -> Профиль и цели
      -> Источники доказательности
```

## 3) Детализация по экранам

### Экран 1. Splash / Welcome
- Цель: вход и краткое объяснение ценности приложения.
- Элементы:
  - кнопка «Начать»;
  - ссылка «Политика и дисклеймер».
- Действие: переход к базовому профилю.

### Экран 2. Onboarding: базовый профиль
- Поля:
  - возраст;
  - пол;
  - рост (см);
  - вес (кг);
  - семейное положение;
  - коэффициент/уровень активности;
  - главная цель.
- Валидации:
  - возраст: 14–100;
  - рост: 120–230 см;
  - вес: 35–250 кг.
- CTA: «Далее».

### Экран 3. Onboarding: расширенный опрос
- Блоки:
  - сон (отбой/подъем/качество);
  - стресс (1–10);
  - питание и вода;
  - ментальное состояние;
  - желаемый % жира и срок цели.
- CTA: «Продолжить».

### Экран 4. Стартовая оценка подготовки
- Вкладки:
  - кардио (время + дистанция);
  - силовые (повторы/вес);
  - мобильность;
  - RPE после теста.
- CTA: «Сформировать план».

### Экран 5. План на день
- Блоки рекомендаций:
  1) сон;
  2) тренировка;
  3) восстановление;
  4) привычка дня.
- Для каждой рекомендации:
  - уровень доказательности A/B/C;
  - ссылка на источник.
- CTA:
  - «Отметить выполнение»;
  - «Было сложно»;
  - «Пропустить с причиной».

### Экран 6. Лог дня
- Поля ввода факта:
  - время пробуждения;
  - выполненные действия;
  - субъективная сложность (RPE);
  - комментарий;
  - вечерний отбой.
- CTA: «Сохранить день и пересчитать завтра».

### Экран 7. Прогресс
- Графики/карточки:
  - регулярность сна;
  - выполнение плана (%);
  - динамика стресса;
  - тренировочная нагрузка.
- Периоды: 7/30 дней.

### Экран 8. Профиль и цели
- Редактирование антропометрии, цели, активности.
- Пересчет плана при изменении цели.

### Экран 9. Источники доказательности
- Список рекомендаций и их источников;
- фильтр по типу (метаанализ/RCT/гайдлайн);
- предупреждения и противопоказания.

## 4) Навигационная модель
- Нижнее меню (MVP):
  - План;
  - Лог;
  - Прогресс;
  - Профиль.
- Модальные окна:
  - быстрый ввод факта;
  - детали рекомендации с научным источником.

## 5) Состояния и edge cases
- Нет данных за день → показывать мягкое напоминание.
- Пропуск 2+ дней → упрощенный план возврата (делоад).
- Высокий стресс 3 дня подряд → автоматический акцент на восстановление.
- RPE 9–10 на тренировке → снижение нагрузки на 10–20%.
